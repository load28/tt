# TASK-166: 에디터 파일 아이콘을 웹사이트 로고로 통일

- **상태**: 완료
- **시작일**: 2026-08-23
- **완료일**: 2026-08-23
- **커밋**: —

## 목적

`.rl`과 `.rlx`의 에디터 파일 아이콘이 시각적으로 과하고 웹사이트 브랜딩과도
다르다. 웹사이트 탭 로고의 단순한 조형을 기준으로 두 파일 아이콘을 통일하고,
라이트·다크 에디터 테마에서 모두 충분한 대비를 확보한다.

## 범위

- 포함: VS Code 확장의 `.rl`/`.rlx` 라이트·다크 SVG 파일 아이콘 교체와 자산 검증.
- 제외: 웹사이트 파비콘, 확장 마켓플레이스 대표 아이콘, 언어 기능 변경.

## 의사결정

### 결정 1: 배경 없는 고대비 자산 하나를 모든 테마에 적용

- **상황**: 웹사이트의 탭 로고와 닮은 형태를 유지하면서 밝고 어두운 에디터
  배경에서 모두 파일 종류가 보여야 한다. 사용자는 TypeScript 파일 아이콘처럼
  테마와 무관한 자산 하나를 요청했다.
- **검토한 대안**: 테마별 반전 자산은 테마에 따라 로고 인상이 달라진다. 파비콘의
  차콜 배경을 그대로 쓰면 화이트 에디터에서 아이콘만 무거운 검은 면으로 보인다.
  투명 배경에 단색 글자만 두면 반대 명도의 테마에서 글자가 사라질 수 있다.
- **선택과 근거**: 배경을 없애고 차콜 외곽선 위에 더 가는 라임 획을 겹친다.
  밝은 배경에서는 차콜 외곽이, 어두운 배경에서는 라임 중심이 모노그램을 구분한다.
  `.rl`과 `.rlx`마다 SVG 하나만 두고 VS Code의 `light`와 `dark`가 같은 파일을
  참조하게 한다.

### 결정 2: 글자를 SVG 경로로 고정

- **상황**: 웹사이트 파비콘은 `monospace` 텍스트를 사용하지만 에디터 아이콘은
  운영체제별 글꼴 차이 없이 작은 크기에서 같은 모양을 보여야 한다.
- **검토한 대안**: SVG `<text>`는 파비콘과 구현이 같지만 시스템 글꼴 메트릭에
  따라 결과가 달라진다. 경로는 자산이 조금 길어지지만 렌더링 결과가 고정된다.
- **선택과 근거**: 소문자 `rl`과 `rlx`를 단순한 모노라인 경로로 그린다. 32px
  viewBox에서 획과 여백을 정수·반정수 좌표에 맞춰 16px 축소 시에도 선명하게 한다.

## 이슈 및 해결

### 이슈 1: 기존 테스트가 테마별 전용 아이콘 파일명을 강제함

- **증상**: VS Code 전체 테스트에서 `the extension registers rlx with its grammar
  and dedicated icons`가 삭제한 `rlx-file-light.svg`와 `rlx-file-dark.svg`를
  기대해 실패했다.
- **원인**: 기존 회귀 테스트가 라이트·다크 자산 분리 자체를 계약으로 고정했다.
- **해결**: `.rl`과 `.rlx` 모두 `light`와 `dark`가 같은 SVG를 참조하며 파일이
  실제로 존재하는지 검사하도록 테스트를 새 단일 자산 계약으로 갱신했다.

### 이슈 2: 전체 VS Code 언어 서비스 테스트의 기존 실패와 장시간 실행

- **증상**: 저장소 `target/debug/rlc`를 PATH에 둔 전체 `npm test`에서도 아이콘과
  무관한 completion/definition/references/rename 테스트 일부가 실패했고, parser
  recovery 테스트 하나가 60초에 실패한 뒤 나머지 테스트가 장시간 종료되지 않아
  중단했다.
- **원인**: 아이콘 계약 테스트만 단독 실행하면 10개가 모두 통과하고 해당 실패들은
  아이콘 자산이나 패키지 참조를 읽지 않는다. 이 태스크 범위에서는 더 조사하지 않았다.
- **해결**: 변경 범위의 `npm run compile`과 `node --test
  server/out/test/grammar.test.js`를 별도로 실행해 통과를 확인했다. 언어 서비스
  실패를 숨기거나 테스트를 수정하지 않았다.

### 이슈 3: 파비콘의 차콜 배경이 화이트 에디터에서 과하게 보임

- **증상**: 웹사이트 파비콘 배색을 그대로 쓴 단일 자산이 화이트 에디터 탭에서
  검은 사각형으로 두드러졌다.
- **원인**: 브라우저 탭용 배경 면까지 작은 파일 모노그램에 옮겨 에디터 배경과
  별개의 무거운 면이 생겼다.
- **해결**: 배경 면을 제거하고 차콜 외곽 획과 라임 중심 획이 밝고 어두운 배경을
  각각 담당하도록 바꿨다.
