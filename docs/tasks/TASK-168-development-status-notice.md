  사용 전 단계이며 API와 언어 동작이 릴리스 사이에 바뀔 수 있다고 설명한다.
  별도의 안정성 등급을 만들지 않으면서 사용자가 알아야 할 기대치를 직접 전달한다.

- **상황**: 사용자는 저장소 README 또는 검색으로 들어온 웹사이트의 개별 문서를

- **검토한 대안**: README 배지만 추가하면 웹사이트 방문자에게 보이지 않는다.
  웹사이트 overview 본문에만 넣으면 개별 레퍼런스 URL로 들어온 사용자가 놓친다.
- **선택과 근거**: README에서는 GitHub가 기본 지원하는 경고 admonition을 사용하고,
  웹사이트에서는 모든 문서 상단에 같은 내용을 담은 배너를 렌더링한다.
