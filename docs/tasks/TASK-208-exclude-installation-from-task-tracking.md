## 의사결정

### 결정 1: 저장소 변경 여부로 설치 작업과 개발 작업을 구분한다

- **상황**: 기존 문구는 모든 작업을 태스크로 규정해, 코드 변경 뒤 공식 setup을
  한 번 더 실행하는 단순 운영 절차도 별도 태스크가 됐다.
- **검토한 대안**: `설치`라는 단어가 들어간 모든 작업을 제외하면 설치기 구현,
  패키징 수정, 설치 문서 변경까지 기록에서 빠진다. `scripts/setup` 실행만
  열거하면 다른 로컬 설치 명령과 상태 확인의 경계가 불명확하다.
- **선택과 근거**: 저장소 추적 파일을 변경하지 않는 기존 산출물의 로컬
  설치·재설치·상태 확인만 운영 예외로 정의했다. 설치 관련 저장소 변경은 개발
  작업으로 명시해 기존 추적 계약을 유지했다.

## 작업 내역

- 2026-08-24: `scripts/setup`, 로컬 컴파일러·에디터 확장 재설치, 설치 상태
  확인을 운영 예외로 명시했다.
- 2026-08-24: 설치 스크립트·패키징·설치 문서·저장소 설정 변경은 계속 태스크로
