## 목적

AGENTS.md의 첫 번째 설계 계약은 전칭 명제다.

> 모든 유효한 TypeScript 파일은 그대로 유효한 `.tt` 파일입니다.

이 명제를 지키는 것이 지금은 `tests/passthrough.rs` **손으로 쓴 475줄**뿐이다.
전칭 명제를 손으로 쓴 사례들로 지키는 것은 품질 보장이 아니라 표본 조사다.

이 계약에는 오라클이 필요 없다는 점이 중요하다. tt 구문이 없는 파일은 정의상
**입력 바이트 == 출력 바이트**여야 하므로, 임의의 TypeScript 코퍼스를 통과시켜
비교하기만 하면 된다. rustc가 crater로, Svelte가 대규모 스냅샷 코퍼스로 하는
일의 tt 버전이다.

## 범위

- 포함:
  - **차등 통과 테스트**: TypeScript 저장소의 `tests/cases/`, DefinitelyTyped,
    실제 npm 패키지 소스를 코퍼스로 삼아 tt 구문이 없는 파일의 바이트 동일성을
    확인한다. 예외는 계약이 허용하는 상대 `.tt`/`.ttx` import 재작성뿐이며
    `--rewrite-imports off`로 끌 수 있다.
  - **`cargo fuzz` 타깃 2개**: (a) 임의 바이트 → 패닉 금지(TASK-214의 보고 경로가
    발동하면 실패), (b) tt 구문 생성기 → 방출 결과가 항상 `tsc`를 통과.
  - 코퍼스를 저장소에 vendoring할지, CI에서 고정 ref로 가져올지 결정. tsgo ref를
    고정한 것과 같은 이유로 부동 `main`은 남의 커밋으로 이 게이트를 깨뜨린다.
  - CI 배치: 전체 코퍼스가 PR마다 돌기에 무거우면 예약 실행으로 분리하고, PR에는
    표본을 돌린다. 분리한다면 무엇이 언제 도는지 문서화한다.
- 제외:
  - 발견된 버그의 수정. 이 태스크는 **찾는 기계**를 만든다. 찾은 것은 각자
    태스크로 등록한다.
