## 목적

Discussion 숙의에 쓰는 GitHub App 정체성을 유지하면서 PR 코드 리뷰 역할을 추가한다.
여러 리뷰어가 같은 head SHA의 코드와 서로의 지적을 검토해 합의안을 만들고, 최종 반영은
사람이 결정한다.

## 범위

- 포함: 기존 Discussion 숙의 유지, PR webhook 수신, head SHA 고정 리뷰 자료 수집,
  다중 라운드 코드 리뷰, 합의 판정, GitHub PR review 게시, 설정·운영 문서와 테스트
- 제외: 코드 자동 수정, 브랜치 push, PR 자동 승인·머지, TASK-245 Variant 구현 변경

- **상황**: Discussion용으로 등록한 네 App을 교체할지, 토론과 리뷰를 병행할지 정해야 한다.
- **검토한 대안**: 새 App 등록 / PR 역할로 완전 전환 / 기존 App으로 두 흐름 병행
- **선택과 근거**: 기존 App으로 Discussion과 PR을 모두 처리한다. 합의에 참여하는
  정체성과 관점은 유지하면서 이벤트 종류에 따라 토론과 코드 리뷰 문맥을 분리할 수 있다.

### 결정 2: 합의는 자동 반영 권한이 없는 검토 증거로만 기록

- **상황**: 리뷰어 합의 뒤 코드 수정이나 머지를 자동화할지 정해야 한다.
- **검토한 대안**: 자동 수정·머지 / 합의 결과 게시 후 사람의 결정 대기
- **선택과 근거**: 동일 head SHA에 대한 합의 결과만 게시한다. 사용자가 최종 검토한 뒤
  반영 여부를 결정한다는 작업 계약을 보존한다.

않고 사람의 최종 판단을 기다린다.
