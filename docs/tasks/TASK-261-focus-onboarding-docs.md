## 이슈 및 해결

### 이슈 1: macOS 임시 경로 별칭으로 확장 테스트 3개 실패

- **증상**: 기본 `./scripts/ci`에서 기대 경로는 `/var/folders/...`, 실제 경로는
  `/private/var/folders/...`로 비교되어 확장 설치 테스트 3개가 실패했다.
- **원인**: macOS의 `/var` 심볼릭 링크와 정규화된 `/private/var` 경로를 문자열로
  직접 비교한다.
- **해결**: `TMPDIR=/private/tmp ./scripts/ci extension`으로 동일 확장 게이트를
  다시 실행해 126개 테스트가 모두 통과함을 확인했다. 문서 변경과 무관한 테스트
  경로 문제이므로 구현은 변경하지 않았다.
